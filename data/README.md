* `Tp` → tampered images (**label 1**)

# COVERAGE Dataset

**COVERAGE (Copy-Move Forgery Database with Similar but Genuine Objects)** is a dataset for **copy-move forgery detection and localization**.

### Dataset

* **100 original + 100 forged image pairs = 200 images**
* Image format: `.tif`
* `image/` — Original and forged images
* `mask/` — Copy, paste/SGO, and forged-region masks
* `label/` — Tampering type and other annotations
* `readme.txt` — Original dataset documentation

### Tampering Types

1. Rotation
2. Scaling
3. Translation
4. Illumination
5. Free-form
6. Combination

### Key Feature

Contains **Similar but Genuine Objects (SGOs)**, making the dataset useful for testing false positives caused by natural self-similarity.

### Source / Download

**Official GitHub:**
https://github.com/wenbihan/coverage

The actual dataset is hosted through the download link provided in the repository.

### Citation

B. Wen et al., **"COVERAGE - A Novel Database for Copy-Move Forgery Detection," ICIP, 2016.**

### Usage

For **non-commercial research only**. Do not upload the dataset itself to our GitHub repository.

## Columbia Uncompressed Image Splicing Detection Dataset

The **Columbia Uncompressed Image Splicing Detection Evaluation Dataset** is a benchmark dataset developed by the **Digital Video and Multimedia (DVMM) Laboratory at Columbia University** for research in digital image forensics and image splicing detection.

Image splicing is a type of image manipulation in which a region or object from one image is copied and pasted into another image to create a forged image. The Columbia dataset is particularly useful for evaluating splicing detection algorithms because the images are **high-resolution and uncompressed**, reducing the effects of JPEG compression and other post-processing operations.

### Dataset Statistics

| Property             | Details                                                                    |
| -------------------- | -------------------------------------------------------------------------- |
| **Total Images**     | 363                                                                        |
| **Authentic Images** | 183                                                                        |
| **Spliced Images**   | 180                                                                        |
| **Image Type**       | Uncompressed color images                                                  |
| **Formats**          | TIFF / BMP                                                                 |
| **Image Resolution** | Approximately 757×568 to 1152×768                                          |
| **Cameras Used**     | Canon G3, Nikon D70, Canon EOS 350D Rebel XT, Kodak DCS 330                |
| **Forgery Type**     | Image Splicing                                                             |
| **Post-processing**  | None after splicing                                                        |
| **Main Scenes**      | Indoor scenes such as desks, laboratories, books, computers, and corridors |

The dataset contains two main directories:

* `4cam_auth` – contains **183 authentic images** captured using a single camera.
* `4cam_splc` – contains **180 spliced images** created by combining content from images captured by different cameras.

### How the Spliced Images Were Created

The spliced images were generated by **copying and pasting visually salient objects** from authentic images using Adobe Photoshop. Each spliced image contains content originating from **two different cameras**. The researchers intentionally avoided additional post-processing so that the dataset could focus on the effects of the splicing operation itself.

The dataset therefore provides a relatively controlled environment for evaluating whether an algorithm can distinguish authentic images from images containing spliced regions.

### Ground Truth

The dataset also provides **edge-mask information** associated with the images. These masks identify the regions around the splicing boundaries and can be useful for **image forgery localization**, in addition to simple binary classification of images as authentic or spliced.

### Role in This Project

In this project, the **CASIA dataset is used for model training**, while the **Columbia Uncompressed Image Splicing Detection Dataset is used as an external testing dataset**.

Using Columbia as an external test set helps evaluate whether the trained model can **generalize to a different dataset and image distribution** rather than simply memorizing characteristics of the training data.

The testing task can be formulated as:

* **Class 0:** Authentic image
* **Class 1:** Spliced/Tampered image

The model's performance on the Columbia dataset can be evaluated using metrics such as **Accuracy, Precision, Recall, F1-Score, and Confusion Matrix**.

### Advantages

* Contains both authentic and spliced images.
* Images are high-resolution and uncompressed.
* Splicing operation is clearly defined and controlled.
* Images originate from multiple cameras, providing variation in camera characteristics.
* Useful for evaluating both **splicing detection and localization**.
* Suitable as an external benchmark for testing the generalization of image-forensics models.

### Limitations

The dataset is relatively small, containing only **363 images**. In addition, most images depict indoor scenes, and the spliced images were created without additional post-processing. Therefore, it may not fully represent the complexity of modern real-world image manipulations involving JPEG compression, resizing, blurring, social-media processing, or multiple editing operations.
